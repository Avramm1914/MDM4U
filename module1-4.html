1.4 - Données de sources primaires et secondaires

Sources de données primaires

Les sources de données primaires proviennent de données recueillies directement de première main, par exemple à l'aide d'enquêtes, d'expériences ou de notes de cours.

Note de cours Source Primaire

Sources de données secondaires

Les sources de données secondaires font référence à des données recueillies par d'autres organismes ou chercheurs, telles que les publications statistiques officielles.
